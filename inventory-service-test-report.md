## 5. Stock Operations and Data Integrity Tests

Automated validation suite executed 17 assertions verifying HTTP responses against direct PostgreSQL queries.

### 5.1 Stock Checking Operations
1. **Query Single In-Stock Product**:
   - Request: `GET /inventory/api/inventory?productName=Iphone%2013`
   - Response: `[{"productName":"Iphone 13","inStock":true}]`
   - DB Verification: `SELECT quantity FROM inventory WHERE product_name = 'Iphone 13';` -> Returned `12`.
2. **Query Multiple Products**:
   - Request: `GET /inventory/api/inventory?productName=Iphone%2013&productName=Macbook%20Pro%2013.3`
   - Response: `[{"productName":"Iphone 13","inStock":true},{"productName":"Macbook Pro 13.3","inStock":true}]`
   - Result: Both products correctly returned.
3. **Query Out-of-Stock Product (quantity = 0)**:
   - Inserted row: `INSERT INTO inventory (product_name, quantity) VALUES ('Sony WH-1000XM5', 0);`
   - Request: `GET /inventory/api/inventory?productName=Sony%20WH-1000XM5`
   - Response: `[{"productName":"Sony WH-1000XM5","inStock":false}]`
   - Result: Correctly reported `inStock=false`.
4. **Dynamic Stock Update Reflection**:
   - Updated row: `UPDATE inventory SET quantity = 15 WHERE product_name = 'Sony WH-1000XM5';`
   - Request: `GET /inventory/api/inventory?productName=Sony%20WH-1000XM5`
   - Response: `[{"productName":"Sony WH-1000XM5","inStock":true}]`
   - Result: API immediately reflected positive stock.
5. **Dynamic Stock Depletion Reflection**:
   - Depleted row: `UPDATE inventory SET quantity = 0 WHERE product_name = 'Sony WH-1000XM5';`
   - Request: `GET /inventory/api/inventory?productName=Sony%20WH-1000XM5`
   - Response: `[{"productName":"Sony WH-1000XM5","inStock":false}]`
   - Result: API immediately reflected stock depletion.
6. **Query Non-Existent Product**:
   - Request: `GET /inventory/api/inventory?productName=NonExistentGadgetXYZ`
   - Response: `[]`
   - Result: Empty list returned cleanly without exceptions.

### 5.2 Scope Note on CRUD
`inventory-service` in the architecture only provides query operations (`isInStock`). It does not implement `POST`, `PUT`, or `DELETE` endpoints. As per instructions to make minimal, evidence-based fixes without architectural alterations, no synthetic CRUD endpoints were injected.

## 8. Errors, Root Causes & Fixes Applied

### 1. Missing Liquibase DDL Migration
- **Error**: Table `inventory` did not exist in database `inventoryservice`. On startup, Hibernate failed with `SchemaManagementException: Schema-validation: missing table [inventory]`.
- **Root Cause**: `db.changelog-master.yaml` only contained a placeholder `SELECT 1;` changeset and did not include table creation changesets.
- **Fix**: Created `src/main/resources/db/changelog/ddl/db.changelog-v1.0.0.sql` creating table `inventory` with identity primary key, `product_name`, `quantity`, and index `idx_inventory_product_name`. Registered via `includeAll: path: db/changelog/ddl` in `db.changelog-master.yaml`.

### 2. Entity Column Name Mapping Alignment
- **Error**: Potential Hibernate column validation mismatch between camelCase `productName` and PostgreSQL column conventions.
- **Root Cause**: `Inventory.java` had `@Column(name = "productName")`.
- **Fix**: Updated `Inventory.java` to `@Column(name = "product_name")` to align with the PostgreSQL snake_case physical column.

### 3. Non-Idempotent Data Loader
- **Error**: Every container restart appended duplicate rows for "Iphone 13" and "Macbook Pro 13.3", multiplying inventory records.
- **Root Cause**: `DataLoader.java` called `inventoryRepository.save(...)` unconditionally without checking table count.
- **Fix**: Added `if (inventoryRepository.count() == 0)` check before seeding initial records in `DataLoader.java`.

### 4. Docker Compose Build and Dependency Definition
- **Error**: `docker-compose.yml` had `pull_policy: always` pointing to remote image `ghcr.io/hoangtien2k3/inventory-service:latest` without a `build:` directive, and lacked a dependency on Keycloak health.
- **Root Cause**: Docker Compose configuration did not build local service artifacts.
- **Fix**: Added `build: ./inventory-service` and `keycloak: condition: service_healthy` to `inventory-service` definition in `docker-compose.yml`.
